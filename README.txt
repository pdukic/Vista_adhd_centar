Vista Učilica

Edukativna aplikacija za djecu s ADHD-om i disleksijom.

Pokretanje:
1. Raspakirajte ZIP arhivu.
2. Otvorite datoteku index.html u web pregledniku.
3. Izradite profil ili odaberite Nastavi igru.

Tehnologije:
- HTML
- CSS
- JavaScript
- localStorage
- SpeechSynthesis API

Napomena:
Aplikacija ne koristi bazu podataka ni Node.js. Profil i napredak spremaju se lokalno u preglednik pomoću localStorage tehnologije.

Dorade:
- kviz sada ima 10 pitanja
- u zadatku slaganja riječi slova se nikada ne prikažu već složena pravilnim redoslijedom
- u težoj razini zadatka "Što je nestalo?" ponuđen je barem jedan predmet koji nije bio prikazan
- produljeno je vrijeme upute u zadatku "Što je nestalo?"
